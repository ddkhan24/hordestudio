# Horde Studio 18.0.3

Fixes replies stopping after malformed model output and preserves configured reply budgets.

- One bounded recovery attempt for confirmed malformed replies, using simpler output instructions. Uncertain provider outcomes are never automatically resubmitted.
- Automatic provider synchronization preserves the server’s saved daily allowance instead of replacing it with an older browser default.
- Explicit changes to the daily allowance still apply. The settings field accepts up to 1,000 requests.

Includes the v18.0.2 live-sync and social interaction fixes. Extract the complete portable ZIP, restart the launcher and reload the browser. Existing life history is preserved.
