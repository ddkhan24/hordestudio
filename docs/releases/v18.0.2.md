# Horde Studio 18.0.2

Fixes VH2 chat and social interactions getting stuck while the life continues running.

- Messages, likes and comments tolerate intervening world revisions while retaining idempotent delivery and target validation.
- Reply validation ignores calendar record ordering and clock-only changes; actual age changes still invalidate the context.
- Reply jobs cancelled before any execution can recover after a cooldown. Failed or uncertain provider requests are not automatically retried.
- Feed refreshes preserve unchanged controls and active comment editing. Comments clear only after server confirmation.
- Pending sync status shows the connection error and a Retry sync action.

Validation: dialogue and social service regression tests, command receipt tests, and an isolated desktop/mobile feed browser test. No generated test media or private chat history is included.

Update: extract the complete portable ZIP, restart the launcher, and reload your browser. Existing life history remains stored locally.
