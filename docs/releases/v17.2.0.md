# Horde Studio 17.2.0

Horde Studio 17.2 fixes a Virtual Human output-boundary failure that could expose private simulation receipts as chat messages.

## Virtual Human reliability

- Added a strict protocol firewall for llama.cpp/Hermes-style `<invoke>` and `<parameter>` tool output, including truncated and HTML-escaped variants.
- Private mood, memory, intention, boundary, truth and autobiographical-state updates can no longer be rendered as dialogue.
- Preserved genuine player-visible dialogue when a provider places it before or after a private tool envelope.
- Pure protocol responses now enter the existing visible-reply recovery path instead of being accepted as completed chat.
- Existing saved leaks are repaired during startup and collapsed into a safe recovery card rather than remaining in the conversation.
- Added a direct **Regenerate reply** action that restores the pre-turn Virtual Human snapshot before retrying, preventing leaked state changes from becoming permanent.
- Recorded blocked-protocol events in private turn diagnostics without exposing their contents.

## Compatibility

This release improves compatibility with OpenAI-compatible local endpoints whose model chat templates serialize function calls as XML instead of returning native `tool_calls`. TinyBrain remains a private local classifier/router and does not generate visible Virtual Human dialogue.

## Portable release

The portable archive includes the local launcher and bridge, Video Adventures runtime, built-in Virtual Humans, bundled runtime media, multiplayer relay source and guide, and the Policy Panic showcase World. Extract the ZIP and run the launcher for your platform; no installer is required.
