# Horde Studio 18.0.1

This patch fixes Virtual Humans 2.0 replies being rejected with “Expression context exceeds the current provider input limit” when the saved audit context pushed the job over the limit even though the model messages fit.

- Check the provider-bound messages instead of counting the separate audit snapshot against the same limit. The 128,000-byte message cap remains enforced.
- Reference pending messages by ID when their exact contents already appear in the conversation, avoiding repeated text in the model context while preserving the full audit record.
- Serialize conversation content without unnecessary Unicode escaping.
- Deliver independent short texts as separate bubbles. Structured replies preserve explicit boundaries; a bounded compatibility fallback handles short plain-text lines. Paragraphs, formatted blocks and calls remain intact. Existing chats are not rewritten.
