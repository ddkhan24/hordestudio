# Horde Studio 18.3.5

Critical reliability release following a deep audit of chat, Worlds, multiplayer, Virtual Humans, video generation, storage, and portable packaging.

- Prevent stalled chat requests, incomplete streamed replies, cross-session saves, and destructive history changes while generation is running. Preserve drafts and paid image results when storage fails.
- Fix Worlds urgency and NPC condition handling so valid turns commit consistently.
- Make multiplayer rerolls, resets, saved hosts, initiative, and canonical mechanics consistent. Protect guest-visible state and make large relay writes recover safely.
- Keep paid Virtual Human image, social, and adviser results through storage retries without billing again. Reject stale worker output and enforce persona ownership.
- Preserve video jobs across timeouts and prevent duplicate paid fallback generation.
- Serialize bridge credential changes and strengthen local HTTP validation.
- Ship checksum-verified Node runtimes for macOS, Linux, and Windows on x64 and ARM64. Exclude private settings, databases, caches, and symlinks from portable builds.

Validation: 129 engine suites, 79 acceptance checks, 35 browser gate commands, source checks, and a packaged browser smoke test across all six modes passed during the audit. Portable verification includes archive integrity, assets, HTTP routes, and Virtual Human kernel boot/replay.

Download the portable ZIP, extract the entire folder, and run the launcher for your operating system. Keep a verified backup before updating, restart the launcher, and refresh the browser.

Live paid provider behavior, deployed Cloudflare relay behavior, and native Windows launching were not exercised locally. GitHub Actions additionally checks Windows launchers and worker encoding. Provider accounts and a compatible local Python installation are required for features that use them.
