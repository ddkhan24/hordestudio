# Horde Studio 18.0.4

Image generation compatibility patch for Virtual Humans 2.0.

- Convert saved and bundled reference images into image data before provider submission, fixing base64-reference errors.
- Support multiple ComfyUI references through workflow image nodes, with clear validation before submission. Configure one connected image node per reference.
- Honor an explicitly selected ComfyUI or local image provider instead of overriding it with a saved cloud renderer.
- Add Google Gemini direct image generation under Person → Photo source, with model and locally stored API-key controls.

Automated reference transport, mocked ComfyUI, adapter recovery and social-profile browser checks passed. Live paid generation was not exercised for this patch.

Download and extract the complete portable ZIP. Restart the launcher and refresh your browser after updating. Existing lives and chats are preserved.
