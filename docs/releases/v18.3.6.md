# Horde Studio 18.3.6

Pip now uses your chosen LLM for conversational answers, grounded in Horde Studio’s built-in product knowledge. This release also adds an illustrated, searchable manual and fixes model discovery.

- Choose Pip’s provider and exact model independently of your character or World, including DeepSeek through OpenRouter. Test the saved assistant and see which provider actually answered. Provider failures are clearly labelled.
- Retrieve relevant passages from 75 manual topics and 172 control explanations. Optional semantic indexing uses your configured embedding model, alongside full-text retrieval. The index contains product documentation; building it and embedding questions can incur provider charges.
- Open User manual below Pip in the sidebar: 51 screenshots, four workflow diagrams, full-text search, alphabetical index, permanent topic links, screenshot enlargement and complete print support. Includes detailed Worlds and Virtual Human setup guidance.
- Fix NanoGPT detailed model metadata, catalogs above 500 entries, exact model IDs and Virtual Human model retention after refresh.
- Include the manual, screenshots and assistant resources in the portable package.

Validation: isolated browser acceptance, knowledge retrieval and embedding tests, NanoGPT provider checks, engine and calibration regressions, and portable archive verification. Generation and embeddings were mocked; live paid providers were not exercised.

Download and extract the entire portable ZIP, run your operating system’s launcher, and refresh the browser after restarting. Back up your library before updating. Configure provider credentials in Settings > Connections, then save your provider and model in Pip’s Assistant settings. Semantic retrieval is optional; full-text knowledge works immediately.
