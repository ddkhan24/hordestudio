# Horde Studio 17.3.0

Horde Studio 17.3 makes Virtual Humans more coherent and turns World Architect into a usable, recoverable authoring workflow for existing Worlds.

## World Architect Agent

- Added a conversational Architect Agent for expanding existing Worlds with places, characters, households, factions, relationships, schedules and world detail.
- Plans large requests in bounded batches and stages typed operations for review before touching the live World.
- Accepts common structured-output variants, recovers supported operations from wrapped or partially malformed model replies, and retries schema failures with exact guidance.
- Resolves generated operations in dependency order, so relationships, characters, households and locations can arrive in any model-output order.
- Keeps exact requested counts honest instead of silently shrinking large additions.
- Separates pre-existing World defects from defects introduced by the proposed batch. Existing issues no longer deadlock unrelated changes.
- Rebuilt **Apply staged changes** as a verified transaction: commit, save, read back from IndexedDB, and retain an undo snapshot.
- Added actionable blockers, durable job checkpoints, dismissible operations and clear saved/error feedback.
- Added household editing and deletion support, safe group merging, character deletion cleanup and searchable relationship authoring.

## Virtual Human cognition and memory

- Separated visible conversation from private state observation. The speaking model focuses on natural dialogue while an optional smaller observer records evidence-backed memory and relationship updates afterward.
- Added stronger output boundaries so private state, tool markup and cognition receipts cannot appear as chat.
- Added provenance-aware memories, corrections, superseded beliefs and forgotten-memory tombstones.
- Added compact context packets that retrieve relevant memories instead of flooding every reply with the full history.
- Improved schedule-aware reply timing: availability, engagement, relationship closeness, message urgency and recent conversation cadence influence when a Human replies.
- Added behavior examples and configurable observer models, including modality-aware evidence handling.
- Improved background initiative consistency between the browser and portable local bridge.

## World reliability

- Fixed Worlds that appeared to reset after refresh when IndexedDB had not finished loading before legacy-storage migration.
- Added persistence read-back verification for World saves and Architect applies.
- Portable launches now keep a stable local origin instead of silently moving to another port and opening a different browser database.
- The launcher can replace an older Horde bridge safely while protecting ports owned by unrelated applications.

## Portable release

The portable archive contains the local launcher and bridge, all four Horde Studio experiences, built-in Virtual Humans, bundled runtime media, multiplayer relay source and documentation. Extract the ZIP and run the launcher for your platform; no installer is required.
