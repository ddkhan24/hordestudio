# Horde Studio 17.1.0

Horde Studio 17.1 makes Video Adventures substantially cheaper to play, expands reference-aware rendering, and fixes two release-blocking World and Multiplayer regressions.

## Video Adventures

- The World Director now plans the complete decision tree as inexpensive text, while video is generated lazily only for the opening and the path the player actually chooses.
- Unused branches no longer consume Fal or HotAPI video credits; the cost estimate reflects only footage that will actually be rendered.
- Added automatic reference planning for openings, newly introduced characters and explicit continuity keyframes without regenerating reference imagery on every shot.
- Added composed opening/reference anchors through Fal image generation when a renderer needs a single visual handoff.
- Added native reference-to-video routing for compatible H3 and Wan paths, with clean prompt-only fallback where a renderer cannot accept the same reference payload.
- Improved character visibility tracking, introduction tracking, prompt construction, cached reference reuse and renderer-aware cost reporting.
- Added Standard and Spicy renderer routes with configurable fallback order, including H3, Wan, LTX and HotAPI options where configured.

## Chat and media capabilities

- Added creator-controlled Chat capabilities for attachments, images, video, image generation and web-aware tools.
- Capability controls remain optional per Chat and are exposed only when the selected provider/model can support them.
- Expanded Fal image/video availability across Chat-adjacent media, Worlds and Virtual Humans while preserving provider-specific controls.

## Reliability fixes

- Fixed explicit World deletion immediately reappearing as a green recovery card. Intentional deletion now removes the manifest, sessions and safety copy atomically.
- Existing orphaned safety-copy cards now include a permanent **Delete copy** action as well as restore.
- Fixed a Multiplayer polling race that could advance the round while silently replacing the newly generated narration with the previous server snapshot.
- Multiplayer commits now resolve in an isolated transaction, pause background synchronization, publish the completed transcript, and verify the canonical relay copy before the UI advances.
- The fix applies to one-player tests, LAN rooms and Internet relay rooms, including OpenAI-compatible local servers such as llama.cpp.

## Portable release

The portable archive includes the local launcher and bridge, Video Adventures runtime, built-in Virtual Humans, bundled runtime media, multiplayer relay source and guide, and the Policy Panic showcase World. Extract the ZIP and run the launcher for your platform; no installer is required.
