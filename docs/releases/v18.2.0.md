# Horde Studio 18.2.0

Virtual Human reliability, long-life storage and private always-on hosting release.

## Faster, steadier conversations

- Keep long transcripts stable instead of rebuilding the complete message DOM after every turn, preserving intentional scroll position.
- Separate foreground replies from optional background work so image activity and life services do not make chat look permanently busy.
- Repair LM Studio state-observer requests after schema-related HTTP 400 responses and retain the actual provider diagnostic instead of reporting every empty result as a timeout or safety filter.
- Make editable exports read-only: exporting a human no longer flushes unrelated queued life commands or rewrites provider configuration.
- Remove a periodic storage-maintenance race that could reject an ordinary life command every five seconds.

## Storage that resolves detail without flattening the person

- Bound fine-grained engine ledgers with verified current-state checkpoints while retaining permanent important and tentpole landmarks.
- Keep exact chat, authored facts, current relationships and state, media, pinned memories and high-priority autobiographical memory.
- Apply visible retention policies to routine and notable indexed memories and compact completed provider-job prompts and duplicate reply data.
- Resize, compress and deduplicate newly imported image assets while preserving transparency and approved references.
- Add service-wide storage inspection and an explicit verified optimizer that pauses active lives, checks free space, compacts old detail and validates replay before reporting reclaimed disk space.

## Private always-on life hosting

- Move a running life to a private VH2 server in a hosting account you control; this is runtime hosting, not merely a cloud backup.
- Keep the cloud copy canonical while the local app maintains a paused recovery mirror.
- Switch the life back through a final sync, or use guarded emergency failover only when the private host is unreachable.
- Authenticate remote access with a private bearer token, exact-origin CORS, restricted remote routes and opaque media tickets. Provider credentials and hosting tokens are excluded from portable exports.
- Add a novice-oriented Railway walkthrough with an app-generated server key, exact settings, persistent `/data` volume and generated HTTPS address. An advanced Docker Compose/Caddy path remains available for experienced server operators.

## Verification

- The complete VH2 service gate passes 67 suites and the creation/chat/save UX gate passes 13 suites with fixture providers only.
- The 100-day storage audit preserves canonical state, replay, exact transcript, media, priority memory and permanent landmarks while reducing its synthetic service database from about 144 MB to about 4 MB after verified optimization.
- Private-host security and restore checks pass 36 assertions; browser move, mirror, return and emergency-failover checks pass 21 assertions.
- Cloud onboarding passes 64 desktop/mobile and real-transfer checks. Storage UI, image normalization, long-chat, observer recovery, startup-interactivity and packaged-human browser audits pass.
- Release tests do not submit paid generation requests.
