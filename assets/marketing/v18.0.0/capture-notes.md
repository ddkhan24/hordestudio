# VH2 launch capture notes

These are screenshots of Horde Studio, captured in isolated demonstration lives. No publisher chat, private player history, API credential or production-life snapshot is included.

## Conversation and simulation

The text demo uses the bundled Aslyn Jonas profile and a synthetic adult contact, Sam. Familiarity was authored for the demonstration. A local test clock was advanced from Friday afternoon in Tempe; background paid generation was disabled. The simulation selected movement from home to the apartment pool, and the live reply referred to that pool. The map and supporting-person views show recorded simulation state, not invented encounters.

Visible replies were generated by the configured OpenRouter `google/gemma-4-31b-it` model. The final chat capture uses the corrected v18.0.1 response contract and shows two distinct saved messages. Earlier unsuccessful formatting captures were replaced. Provider diagnostics were limited to six calls with 1,000 output tokens each; diagnostic calls are not all shown as conversation turns.

## Photo demonstration

The new selfie was generated with Codex's built-in image generation tool using a clothed Aslyn identity photo and her approved living-room reference. Its prompt is in `media/aslyn-demo-selfie-prompt.txt`. The image was then imported and delivered through Horde's native photo commands in a separate paused demonstration life at home, with the living-room zone and approved references frozen in the capture. This demonstrates reference continuity and actual photo delivery; it is not an app-initiated image-provider request or a spontaneously chosen photograph. Clothing was directed for this staged image.
